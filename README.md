# Cardboard Robots — micro:bit Sensor Lab tutorials

Guided-build tutorials for the Year 7 Digital Technologies unit *Cardboard Robots*,
Meridan State College. Each markdown file is a [MakeCode for micro:bit](https://makecode.microbit.org)
tutorial: build a short sensor program step by step, test it in the simulator, then try a challenge.
They go with the QLearn page *Sensor Code Lab* (Lesson 2).

## Notes

- `### @diffs true` highlights the new block at each step.
- Each challenge step lists the blocks it needs in a `ghost` fence, so they are in the
  tutorial's toolbox without being shown as the answer.
- Editing: change the markdown here and the live tutorials update. Keep the copy in the
  unit folder (`Student Resources/Sensor Code Lab tutorials/`) in step.
